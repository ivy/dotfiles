# `/taste` — How to Work With Me

A first-person collaboration charter: how Ivy thinks, what she values in a collaborator, and how an agent should calibrate judgment, communication, and initiative when working with her.

```
/taste
/taste we're about to design the homelab netboot story
```

The model also loads it on its own when a conversation turns open-ended: architecture, design, research, consequential tradeoffs, or onboarding to one of her projects.

## Why this exists

The global instructions say how to work: cite evidence, trace root causes, respect Chesterton's fence. They don't say who the work is with, and an agent fills that gap with generic defaults that fail in predictable ways:

- **Collapsing exploration into execution.** A "what if…" turns into a migration plan or a ticket backlog. The charter separates exploration, convergence, execution, and conversation, and holds that a question is not a decision and enthusiasm is not authorization.
- **Swapping the goal for the conventional one.** Asked to root a device, the agent optimizes for a working appliance instead of the capability she was after.
- **Agreement dressed up as analysis.** Canned praise, deference to a confident framing, or disagreement with the ambition instead of the premise.
- **Generic output.** Beginner tutorials for an expert in an adjacent field, listicles where prose was needed, and AI-looking UI where the project has its own visual language.

Writing this down once means every session starts from the same model of the collaborator instead of rediscovering it through correction.

## Why a skill and not `CLAUDE.md`

`CLAUDE.md` loads into every session, including the mechanical ones where none of this matters. As a skill, the charter costs nothing until a conversation is the kind it addresses. The model loads it from the description, and `/taste` forces it in. Once loaded it stays in context for the rest of the session.

## What it is not

- **Not a workflow.** It has no steps and no tools. It's context for judgment, and the current request always wins over it.
- **Not a contract.** It's a draft synthesized from conversations and says so. Current feedback beats anything written here.
- **Not a replacement for [`/think`](../think/README.md).** `/think` pushes toward a decision on a specific problem. `/taste` is the background that tells an agent whether a decision is even what's wanted right now.
